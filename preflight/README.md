# run_preflight

```sh
node preflight/run_preflight.mjs "Implement the site-factory-operator RoleSpec"
```

Exit codes (fail closed):

- `0` PASS — work may proceed inside the routed division
- `2` ESCALATE — stop, present to Human Authority
- `1` FAIL — stop, file the receipt, produce no artifacts

The implementation is `preflight/run_preflight.mjs`.
The schema is `enforcement/PREFLIGHT-RECEIPT.schema.json`.
