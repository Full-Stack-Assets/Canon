# Agent Operating Company Framework
Version: 1.0
Date: 2026-08-18
Status: Active

## Purpose
The Agent Operating Company (AOC) is the governed operating system under
permanent Human Authority. Canon is its second brain and single source of truth.
Every user input must enter this framework without exception.

## Core Structure

```
HUMAN AUTHORITY
└── AGENT OPERATING COMPANY
    ├── 10 PERMANENT DIVISIONS
    ├── CANON                          ← second brain / Global Library
    └── AGENTIC EXECUTION LAYER
          ├── Portable Adapters
          ├── Factories / Workflows
          ├── Temporary Agent Pods
          ├── Projects / Work Orders
          ├── Artifacts / Actions
          ├── Verification / Evidence
          └── Learning Loop → writes back into Canon
```

## Non-Negotiable Rules
1. Every single user input routes through this structure and is grounded in Canon.
2. Canon is the only source of truth for roles, skills, policies, and evidence.
3. Agent instances are temporary and task-scoped.
4. No runtime may approve its own consequential output.
5. High-consequence actions require an explicit approval record in Canon.
6. Aether Portfolio remains a separate product surface.

## Standard Execution Path (Every Input)
Objective
→ Task / Work Item
→ Preflight Gate
→ Workflow
→ Workflow Nodes
→ Required Capabilities
→ Resolved Execution Routes
→ Temporary Agent Instance
→ Skills + Tools + Providers + Runtime
→ Artifacts / Actions
→ Independent Verification
→ Approval (where required)
→ Receipt
→ Evidence written back to Canon

## 10 Permanent Divisions
1. Strategy & Portfolio Governance
2. Knowledge & Research
3. Solution Architecture & Design
4. Code & Artifact Production
5. Quality, Review & Security
6. Operations & Site Factories
7. Identity, Credentials & Access
8. Economics, Metering & Monetization
9. Verification, Audit & Evidence
10. Learning, Evaluation & Improvement

## Relationship to Other Surfaces
- Canon = memory and governance registry
- Aether Portfolio = portfolio command center (separate product)
- Agent Operating Company = the full governed system that uses Canon
